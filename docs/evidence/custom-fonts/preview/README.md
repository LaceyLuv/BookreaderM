# API36 실제 캡처

소스 `4449f1e6094a5fb9546ac4ed4ea3de04c2f4b351`, run 40052571291/API36 native 검사 중 캡처했다.
TXT는 SAF로 가져온 Nanum Gothic 파일과 굵게를 적용한 화면이며, 캡처 시점은 재배치 직후여서 쪽수 계산 중이다.
EPUB은 자체 생성 OTF를 적용한 화면이다. OTF에 없는 문자는 플랫폼 대체 글꼴로 표시한다.
글꼴 파일 로드 상태와 computed font-weight=700은 별도 실제 WebView 검사에서 확인했다.
픽셀 그림만으로 font-face 로드 성공이나 위치 보존을 판정하지 않는다.
