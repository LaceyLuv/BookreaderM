# 사용자 글꼴·글자 굵기 — 0.5.0

사용자가 요청한 APK 전달 방식은 [배포 운영 방안](APK_DISTRIBUTION.md)에 기록했다.
이번 제품 변경은 사용자 글꼴 등록과 글자 굵기 선택이다. 배포 자동화 workflow 구축은 별도 계획이다.

## 사용 방법

1. 독서 화면 중앙을 탭하고 TXT에서는 **글자·화면**, EPUB에서는 **설정**을 연다.
2. **내 글꼴 → 글꼴 파일 추가**에서 기기에 있는 TTF·OTF 파일을 선택한다.
3. 등록된 글꼴과 **보통 / 굵게**를 선택해 미리보기로 확인한다.
4. **적용**을 누르면 본문에 반영된다. 같은 설정을 다른 TXT·EPUB에서도 사용한다.

등록만 하고 설정 창을 닫으면 글꼴은 목록에 보관되지만 본문의 적용 설정은 바뀌지 않는다.
기존 기본 고딕/명조·나눔고딕/명조도 계속 선택할 수 있다.
등록 파일은 앱 내부에 복사되므로 원본을 이동·삭제하거나 원본 접근 권한이 끝나도 사용할 수 있다.
동일한 파일을 다시 등록해도 중복으로 저장하지 않는다. 삭제는 앱의 복사본에만 적용한다.
사용 중인 글꼴은 다른 글꼴을 적용한 뒤 삭제할 수 있다.

## 적용 범위와 위치 보존

TXT는 미리보기·본문·페이지 경계·전체 쪽수 측정에 같은 글꼴과 굵기를 사용한다.
설정 변경 후에는 기존 UTF-16 위치를 복원하고 현재 레이아웃의 쪽수를 다시 계산한다.
EPUB은 Readium의 font-family와 font-weight 설정을 사용한다. 글꼴/굵기를 직접 선택하면 출판사 스타일 우선을 해제한다.
출판사 스타일 유지를 다시 켜면 해당 EPUB 스타일을 우선한다. 기존 full locator를 유지하며 복원 전 새 진행도를 저장하지 않는다.
그림으로 된 만화의 글자는 글꼴/굵기 변경 대상이 아니다.

굵게는 플랫폼에서 합성한 결과일 수 있다. 정적 글꼴 파일 자체가 굵은 경우 보통은 그 파일의 기본 모양이다.
선택한 글꼴에 없는 문자는 플랫폼 대체 글꼴로 표시한다.

## 저장과 한도

TTF·OTF 단일 파일을 지원하며 TTC·WOFF·WOFF2·압축파일은 지원하지 않는다.
파일당 20MiB, 최대 12개·합계 100MiB이며 읽기 제한은 60초다. 실제 스트림 길이도 검사한다.
잘못된 파일과 용량 초과는 거부하며, 취소·저장 실패 시 미완료 임시 파일을 정리하고 기존 설정·글꼴·책을 유지한다.
내부 복사본 등록이 이미 완료된 직후 설정 창을 닫은 경우에는 등록된 글꼴이 목록에 남을 수 있다.
이름 대신 SHA-256 ID를 내부 경로로 사용하고 등록 완료 시 디렉터리를 이동해 부분 파일 노출을 막는다.
기존 설정 JSON에 새 필드가 없으면 기본 글꼴과 보통 굵기로 읽는다. 누락된 사용자 글꼴은 내장 글꼴로 표시한다.
[ADR 0007](adr/0007-user-fonts-and-weight.md)에 구현과 자원 공급 방식을 기록했다.

## 검증 상태

로컬 컴파일·lint·필수 CI 스크립트 PASS. 단위 검사 Android 71/shared JVM 74/EPUB 16 모두 PASS다.
추가 단위 검사는 TTF·OTF 구조와 손상·범위 초과·겹치는 테이블을 검증한다.
추가 native 검사는 실제 파일 선택/권한 전달, TTF 적용·굵기·Activity 재생성·책 재열기·중복·삭제,
EPUB OTF font-face의 실제 loaded 상태·700 굵기·재열기·기존 locator 보존을 검증한다.
[build 40050209007](https://github.com/LaceyLuv/BookreaderM/actions/runs/40050209007)의 164개와
[device 40052571291](https://github.com/LaceyLuv/BookreaderM/actions/runs/40052571291)의 API26/34/36 각각 native60+host6이 PASS다.
최종 검증 소스는 `4449f1e6094a5fb9546ac4ed4ea3de04c2f4b351`다. 필수 사례·원본 XML·artifact digest·실제 force-stop 후 PID 교체를 대조했다.
첫 실행의 기존 TXT 쪽수 대기 timeout 등 중간 실패와 같은 소스 재검증 결과를 [증거 목록](evidence/custom-fonts/README.md)에 함께 보존했다.
실제 휴대전화 설치와 사용자 글꼴 전체 호환성 검사는 NOT_RUN이다.
설치 시험용 APK와 20MB 미만 임시 ZIP의 생성물·서명 정보는 [설치 안내](INSTALLABLE_APK.md)를 따른다.
